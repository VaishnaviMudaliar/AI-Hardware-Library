# AI Hardware Library

An open-source collection of reusable RTL IPs, digital IC design examples, and FPGA/ASIC implementations for AI accelerators.

## Vision

This repository aims to provide modular hardware building blocks for modern AI systems, ranging from activation functions and arithmetic units to Transformer inference accelerators.

## Current Development

- 🚧 Matrix Engine
- 🚧 ReLU Accelerator
- 🚧 Softmax Accelerator
- 🚧 LayerNorm Accelerator
- 🚧 Top-K Accelerator
- 🚧 Top-p Accelerator
